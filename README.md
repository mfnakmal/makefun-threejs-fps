Autonomous round-based tactical first-person shooter in Three.js for make.fun's [threejs-fps-02](https://make.fun/bounty/threejs-fps-02) bounty ($1,000 prize pool).

## Features
- Counter-Strike style round-based mechanics with bots
- First-person mouse-look, recoil & spread dynamics, tactical movement
- Fully offline static browser client powered by Three.js 0.187.0
- Automated dossier generator for pairwise judge evaluation

## Run
```bash
node serve.ts
# open http://localhost:8080
```
